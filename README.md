# Bakkenbeheer

Simpel appje om de drink vouchers bij te houden (528 Ibiza):

- 15 vouchers voor bier of water
- 3 vouchers voor premium drinks of soda

Tik op een voucher of op "Gebruik 1 voucher" om hem af te strepen. Per ongeluk getikt? Tik op "Herstel" of tik nog een keer op de voucher.
Elke telefoon houdt zijn eigen stand bij. Er is geen account, database of server nodig.

## Op je iPhone zetten

1. Open de link in **Safari**.
2. Tik op **Deel** (vierkantje met pijl omhoog).
3. Kies **Zet op beginscherm** en tik op **Voeg toe**.
4. Open Bakkenbeheer voortaan via het icoontje op je beginscherm. Hij werkt dan ook zonder bereik.

Let op: de stand in de app op je beginscherm staat los van de stand in Safari. Gebruik dus steeds dezelfde (het liefst het icoontje).
